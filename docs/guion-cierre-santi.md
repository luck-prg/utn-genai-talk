# Cierre de la charla

Recorrido sugerido de **17 minutos**, con margen hasta 20 para intervenciones breves. Las preguntas abiertas de la slide 124 quedan fuera de este tiempo. El guion desarrollado está en `meta.notes` de cada archivo y se puede consultar junto con esta hoja de ruta antes de presentar. La web actual no tiene una vista de notas del orador.

Para una versión de **15 minutos**, dedicar 1:30 a las slides 122, 122.20, 122.40 y 122.60. Para llegar a 20, usar el margen en dos intervenciones breves del público, sin extender la presentación de herramientas.

## Notas para el relato

- Recuperar ejemplos que el público ya vio. El cierre conecta lo aprendido con decisiones propias.
- En el ejemplo de reservas, distinguir que una prueba del flujo habitual pase de que el sistema responda correctamente ante concurrencia.
- En la reflexión sobre aprendizaje, dejar unos segundos de silencio. La pregunta es individual.
- En los escenarios futuros, usar la formulación condicional de la slide: «si delegamos tareas más largas…». La adopción y los resultados dependen del proyecto.
- Para la electiva, la invitación queda general hasta contar con el nombre oficial y un enlace confirmado. No se anuncian programa, nivel, horarios, requisitos ni inscripciones.
- Para GEMIS, invitar a conocer proyectos y consultar formas de participación. Los enlaces llevan al sitio institucional, sin anunciar vacantes.
