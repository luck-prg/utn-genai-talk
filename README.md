# Diseñando el futuro del desarrollo con GenAI

Material base para la charla de UTN sobre desarrollo de software asistido por agentes de IA.

## Tesis

> El valor de desarrollar software de calidad se duplicó.

La IA generativa no elimina el rol del ingeniero: lo desplaza hacia una capa de mayor abstracción. El trabajo ya no consiste solo en escribir código, sino en diseñar contexto, especificaciones, evaluaciones y sistemas de orquestación para que los agentes produzcan software escalable, predecible y mantenible.

## Temas principales

- Context Engineering
- Spec-Driven Development
- Evaluaciones de agentes
- Orquestación multi-agente
- Buenas prácticas para desarrollo estructurado con GenAI
